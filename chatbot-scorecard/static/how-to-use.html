Three ways to use the scorecard

The scorecard helps you evaluate a chatbot across key metrics, understand areas of strength and identify opportunities for improvement.

Option 1: Complete the scorecard online

  • Open the Chatbot Scorecard tab and rate each metric as "High," "Medium," or "Low" based on the scoring criteria provided under each metric and based on your evaluation.
  • Once all metrics have been rated, select Calculate Score to view your results, including: overall score, results by domain/dimension, results by individual bucket, and the ratings and weights applied to each metric.
  • Save your results as a PDF, or export the assessment as a JSON file to keep or share with another team.
View an Example PDF
Chatbot Scorecard

Option 2: Host the scorecard on your own site

  • The scorecard is available as code on GitHub and can be hosted on your own website or internal platform.
  • This option allows your team to manage access, make changes to the code, and maintain its own version of the scorecard.
  • It may be useful for organizations that want to customize the scorecard, integrate it into an existing website, or manage their own deployment.
View the Code on GitHub

Option 3: Export and share your assessment

  • If you want to share an assessment for yourself, with another team or your colleague, you can download the completed assessment as a JSON file.
  • The JSON file contains the chatbot information, metric ratings, dimensions, buckets, weights, and assessment data.
  • You can import the JSON file using the Import button on the scorecard to continue or review the assessment.

Scorecard Data: The scorecard runs entirely within your browser. Assessment responses are not transmitted to or stored on our servers. Responses may be saved locally in your browser to allow you to continue your assessment later.
