## About The Project

This project was developed as a collaboration between graduate students at Columbia University’s School of International and Public Affairs (SIPA), under the guidance of Professor Savita Bailur, and Girl Effect. The goal was to create a practical framework for evaluating whether SRH chatbots are safe, effective, inclusive, and responsive to users’ needs.

As AI-enabled SRH chatbots expand, there is a growing need for standardized tools to assess quality beyond simple engagement metrics. This framework fills that gap by offering a structured scorecard covering more than 30 weighted metrics across key areas such as:

- product design
- information reliability
- privacy and security
- user safety
- accessibility
- monitoring and learning
- sustainability

The framework is intended as a public good for funders, developers, implementers, and other stakeholders seeking a shared benchmark for quality and accountability in SRH chatbot design and deployment.

## Getting Started

This is a static website, so there is no build step or package installation required.

### Prerequisites

You only need a browser and a local web server if you want to preview it through localhost.

### Installation

1. Clone or download the project folder.
2. Open the site directly in a browser, or serve it locally.
3. To run a local preview:

```bash
cd /path/to/chatbot-scorecard
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/static/
```

## Usage

The site is meant to be used as an evaluation and decision-support tool.

- Use the About page to understand the framework and rationale.
- Use the User Guide to understand how to assess a chatbot.
- Use the Metrics page to review the evaluation criteria.
- Use the Scorecard page to rate and calculate the final score for the chatbot.
- Use the Contact and Terms pages for project support and legal information.
